# Deep Interview Spec: PoolMind — 救生员管理系统（香港）

## Context

用户经营一家香港救生员外判公司，员工全部为兼职。现有流程完全跑在 WhatsApp 上：群发某月长更/某日短更招募 → 救生员私信报可上班日子 → 主管手动排更 → 发薪时手动逐人计算工资。用户的核心诉求：**主管只负责"和人对接"（谈工资、拍板），其余人事杂务（汇总可用性、排更、算工资、追确认）全部由系统智能化完成。**

## Goal

建一个**响应式网页应用**（架构预留日后原生 App），让香港救生员外判公司的主管：在 WhatsApp 群发一条带链接的招募 → 救生员点链接完成资格验证并报名 → 主管在站内聊天里谈定时薪、按确认键 → 系统自动完成排更、每晚自动算出每人应付工资、用状态机跟踪每笔工资是否已付并双向确认。主管的人工介入仅剩：谈工资、按确认、调整更表异常、去银行转账。

## Constraints

- **地区**：香港 — 繁体中文界面、港币（HKD）、香港救生员资格证件。
- **平台**：响应式网页优先（点 WhatsApp 链接即用，无需装 App）；技术选型需预留日后原生 App（API 与前端分离）。
- **更表即考勤**：不做打卡/GPS 签到。排入更表即默认出勤；请假/旷工/换更由主管手动改更表；名字在更表上就计薪。
- **多场地异构**：多个屋苑泳池，各自的更次时间、人数需求不同。创建泳池必须填至少一个模板（救生员人数、默认时薪、**每天的更次定义**——如早更 7:00-15:00、晚更 14:00-22:00），可选第二个"冬季规格"模板，支持一键冬夏切换。
- **报名粒度到更次**：救生员报长更可用性时勾选到"某天的某个更次"级别，不是只报整天。工资时数 = 更次时长。
- **价格对救生员不可见**：默认价只是主管端参考；救生员在任何界面都看不到价格，只有谈定后在自己的工资单里看到自己的时薪。
- **时薪个人化，三层覆盖**：单日单独改（更表每格可编辑时薪）> 该救生员×该泳池绑定价（谈一次自动沿用，主管可手动改）> 泳池模板默认价。确认报更时主管手动输入，界面显示参考价。**不做 AI 读聊天提取工资**——聊天只是沟通工具。
- **过去锁死，只允许调整项**：每天午夜 12 点后，过去日期的更表不可改并据此更新工资表；迟到罚款等用"加钱/扣钱调整项（附原因）"挂在当天，原时数工资不可改，结算自动跟进。
- **先自用，预留平台化**：本期单公司使用，顶级主管账号初始化时创建；数据模型预留多公司（多租户）隔离，日后可开放判头注册。
- **拖拽硬约束**：更表编辑时，救生员名字只能拖进他报过可上班的日子。
- **主管层级**：主管可创建子主管账号并分配屋苑泳池，形成垂直链；权限 = 自己管辖泳池 + 下级全链泳池；工资单按主管管辖范围生成。
- **双角色**：主管上传资历（同样 OCR 验证）后可兼救生员，把自己排进更表、看自己工资；自付工资直达"双向已确认"（不可撤销、无 7 天倒计时）。
- **转账在系统外**：主管自行银行转账，系统只做金额计算与确认跟踪，不接支付渠道。

## Non-Goals

- 打卡 / GPS / 拍照考勤系统
- AI 从聊天记录自动提取工资数字
- 银行 / 支付平台对接、自动转账
- 替代 WhatsApp 的群发功能（招募仍在 WhatsApp 群发，系统只提供报名链接）
- 原生 iOS/Android App（本期只预留架构可能性）

## 核心流程与规则

### 1. 招募与报名
1. 主管在系统内创建招募（月度长更 或 单日短更），生成链接，自己贴到 WhatsApp 群。
2. 访客点链接 → 输入姓名 + 上传救生员证 → **OCR 识别**，证上姓名与输入姓名一致即可进入站内聊天（访客态）。
3. 长更：报名时勾选该月可上班的**更次**（更次由泳池模板预定义）。短更：报名即视为该更次可用（与长更本质相同）。
4. 多人报同一短更：按报名时间顺序展示给主管；主管点进报名列表逐个用内置聊天议价。
5. **一人多报与"抢人"**：救生员可同时报多个短更。任一主管确认后，该人从其他泳池的待确认列表中隐藏（冲突隐藏）；该确认若被取消，则恢复显示回其他列表，继续等待确认或拒绝。
6. 主管按"确认"键：输入谈定时薪（显示泳池默认价参考，救生员看不到）→ 救生员此时必须注册正式账号补齐资料（与访客态初级资料合并）→ 进入更表。
7. 未被确认的普通报名，救生员可随时撤回，不通知任何人。

### 2. 智能排更
- 主管端更表：日历视图，手动拖拽编辑（硬约束：只能拖进该人报过的可用日），或**一键排班**。
- 一键排班优先级：① 泳池**偏好名单**成员最优先，且满足"该泳池空位中至少 N 个来自偏好名单"的规定；② 连续性（同一人同一泳池连续上更）；③ 其他。无法完全满足时尽力满足并照样显示方案，由主管手动收尾。

### 2b. 更表变动与通知
- 救生员取消**已确认班次**：弹二次确认框（提示"将立即通知主管"）→ 确认后**立即 App/站内通知**该泳池管辖主管。
- 短更被本人取消 → 班次重新开放，并恢复之前因冲突被隐藏的其他报名者。
- 长更排班被本人取消 → 该格空缺，主管用排班工具箱（一键排班/手动拖拽）处理。
- 救生员不想上班需逐个取消所报班次；请假/旷工等其余异常仍由主管手动改更表。

### 3. 工资与支付确认
- 每晚 00:00 自动汇总：每人 时薪 × 更表时数 = 应付金额，生成/刷新工资单（含每日明细）。
- 主管端：按管辖泳池看每个救生员的月度应付，**首屏即见未结清余额**；可下钻单日明细单日确认，或在列表对整人一键确认。
- 救生员端：自己的更表 + 工资单（按主管分组），可单日确认收款。
- **支付确认状态机**（逐字采纳用户规格）：
  - 待支付 →(主管确认)→ 支付方已确认
  - 待支付 →(员工确认)→ 员工已确认（待自动），启动 7 天计时，7 天后自动替主管确认
  - 支付方已确认 →(员工确认)→ 双向已确认
  - 员工已确认（待自动）→(主管确认)→ 双向已确认，终止计时
  - 员工已确认（待自动）→(7 天到期)→ 自动确认支付
  - 待支付 →(主管忽略)→ 已完结（忽略）
  - 待支付 →(主管兼救生员自付)→ 双向已确认（系统自动代完成员工端，无倒计时）
  - 撤回：支付方已确认→主管可撤回；员工已确认（待自动）→员工可撤回；双向已确认/自动确认/已完结（忽略）一律不可撤销；自付确认不可撤销。

### 4. 账号与权限
- 角色：主管（可分级）、救生员、主管兼救生员。
- 主管创建子主管并分配泳池；权限沿垂直链向下聚合。
- 员工档案：基本资料、资历证书（OCR 验证记录）、与各主管谈定的时薪历史。

## Acceptance Criteria

- [ ] 主管可创建屋苑/泳池，含 ≥1 个模板（人数+默认时薪）与可选冬季模板，一键冬夏切换生效于后续排更
- [ ] 主管可发布长更/短更招募并获得可分享链接
- [ ] 访客点链接：姓名+证件上传，OCR 姓名一致才放行进聊天；不一致被拒并提示
- [ ] 报名确认时强制注册，访客资料自动合并
- [ ] 更表拖拽无法把人放进未报可用的日子（前后端双重校验）
- [ ] 一键排班满足：偏好名单最少人数 → 连续性 → 尽力而为并展示方案
- [ ] 每晚 00:00 定时任务刷新工资单；金额 = Σ(时薪 × 更次时数)
- [ ] 主管首屏可见每个救生员未结清余额；单日确认与整人确认都会即时更新余额
- [ ] 支付状态机 7 条转换 + 4 条撤回规则全部有自动化测试覆盖（含 7 天定时自动确认）
- [ ] 子主管只能看到/操作自己管辖链内的泳池、更表、工资单
- [ ] 主管兼救生员：上传资历后可排自己进更表，自付确认直达双向已确认且不可撤销
- [ ] 救生员端可见自己更表与按主管分组的工资单，可单日确认收款
- [ ] 全站繁体中文、金额显示 HKD、手机浏览器可完整操作
- [ ] 泳池模板含更次定义（时段+时数）；救生员报名勾选到更次级别；工资时数取自更次时长
- [ ] 救生员任何界面看不到默认价/他人价格；自己的时薪只在工资单可见
- [ ] 一人多报：A 主管确认后该人从 B 池待确认列表隐藏；A 取消后恢复显示
- [ ] 取消已确认班次：有二次确认框，确认后管辖主管立即收到通知；短更取消班次重开并恢复被隐藏报名者；长更取消该格空缺
- [ ] 未确认报名可静默撤回（无通知）
- [ ] 时薪三层解析正确：单日改价 > 人×池绑定价 > 泳池默认价；绑定价谈一次后新排班自动沿用
- [ ] 午夜后过去日期更表不可编辑（时数/时薪/人员均锁定）；仅可添加加钱/扣钱调整项（必填原因），工资单含调整项自动重算
- [ ] 顶级主管账号由初始化流程创建；数据模型含公司/租户维度（本期单租户运行）

## Technical Context（greenfield 建议，待计划阶段定案）

## Verification（实现完成后的端到端验证）

1. 走通完整主流程：创建泳池（含模板）→ 发短更招募 → 以访客身份点链接报名（OCR 通过/失败各一次）→ 聊天 → 确认+填时薪+注册 → 出现在更表。
2. 一键排班：构造"偏好名单不足 / 连续性冲突 / 无法满足"三种数据，验证方案生成与降级展示。
3. 拖拽约束：尝试把人拖进未报的日子，前后端都应拒绝。
4. 工资：手动触发夜间汇总任务，核对金额 = 时薪×时数 + 调整项；验证时薪三层解析（单日 > 人×池绑定 > 默认）；验证状态机全部转换与撤回路径（7 天到期用时间模拟）；验证过去日期锁定后仅调整项可添加。
5. 权限：以子主管登录，确认看不到管辖链外的泳池与工资单。
6. 手机浏览器（375px 宽）全流程可操作，界面为繁体中文、金额为 HKD。
