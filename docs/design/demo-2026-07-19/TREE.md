## 页面层级

```
主管端 (01-supervisor.html) —— 底栏 4 tab：首頁 / 訊息 / 工資 / 我的
├── S1 首頁  ★本轮合并舊 S2
│   ├── 天气栏：警告信号(点击循环 雷暴→黃雨→紅雨→黑雨→天晴) + 日期 + 实时时间 + 香港天文台跳转
│   ├── 招募情报流（全港，含「我發布」，可报名/联系）—— 与救生员端一致
│   ├── 我的泳池（管理入口）
│   │   └── → S3 单池月更表
│   ├── 今日待处理 → S5 / S4
│   └── ＋发布招募 → S7
│
├── S2 【已作废】合并入 S1，ID 永不复用
│
├── S3 单池月更表  ★本轮改 Excel 式垂直日历
│   ├── 一行一日（日期｜星期｜排班），周六周日淺紅底
│   ├── 「缺人＋」行 → S5 处理报名
│   └── 名字段 → 交换/移除选单（demo 提示）
│
├── S4 訊息  ★本轮新增 WhatsApp 式会话列表层
│   ├── 会话列表（陳大文/阿明/阿強/細龍/阿水，头像+末条+未读)
│   └── 点入 → 聊天线程（发消息 / 发📍泳池详情卡片 / 返回列表）
│
├── S5 待处理报名 → 确认入表弹窗（时薪）→ 回填 S3 的 7/19 行
├── S6 工资（未结清总额 / 一键确认已付 / 导出 Excel）
├── S7 发布招募（选字段公开 → 生成 WhatsApp 文案）
└── S8 设置（风格 A/C 切换 + 4 主题色 + 账号）

救生员端 (02-lifeguard.html) —— 底栏：搵工 / 我的更 / 訊息 / 工資 / 我的
├── L1 注册（用户名/密码/真实姓名/证件OCR壳/WhatsApp验证壳）→ L2
├── L2 搵工（招募列表：情形A直接报名 / 情形B联系以报更 / 长更勾选）
├── L3 我的更表（同事+主管 WhatsApp 联系）
├── L4 我的工资（按主管分组，确认已收）
└── L5 聊天（发消息 → 主管回卡片 → 接受）

平台管理员端 (03-admin.html) —— 底栏：审核 / 用户 / 设定
├── A1 证件审核（通过/驳回/待复审）
└── A2 用户列表（未认证/已认证/待复审/驳回筛选）
```
