# 访谈记录：2026-07-14（Round 16–23 + 账号体系深挖）

> 上一次：2026-07-12 完成 R0–R15（模糊度 3.3%）。本次把待问清单全部清零，模糊度降至约 1%。

## R16 通用链接与分层披露
**问**：一个招募帖（链接）对应什么范围？链接何时失效？
**答**：长期通用链接——公司一条固定链接挂群里，进去看到所有在招的更。并提出行业现象：市面上所有主管都不会在公海说具体泳池和工资，只有救生员私信才谈价钱和位置，这是要内置通讯的原因。
**分析（已确认）**：原因 = 防同行截胡、保议价空间、防员工比价、信息即筹码。
**方案（已确认）**：分层披露——发招募时主管**自选公开哪些字段**（日期/区域/更次时间/地铁站/泳池模板备注等）；聊天中主管点"**发送泳池详情卡片**"（附接受按钮）才露具体屋苑；排更后救生员端更表显示完整信息。泳池模板增加"备注"字段。

## R17 会话模型
**答**：人对人永久会话（类似 WhatsApp），所有报名/卡片/议价历史同一对话框，永久保留。

## R18 模板体系强化
**答**：创建某泳池某月更表时选模板；创建后改模板可选"某日后生效"或"全部改变"，冲突列给主管。模板要很细：可按星期几定义（周一只有下午更、周三无更）；可建多于两个模板，"冬天/夏天"只是老板起的备注名。

## R19 证书过期
**答**：只提醒不禁排。到期提醒双方；过期高亮三处：聊天框、救生员资料页、更表上的名字。

## R20 主管首屏
**过程**：用户先问"首屏是什么"（= 登录后第一眼的主页/仪表盘）；然后明确**不要**未结清余额（移工资页）。
**定案**：① 今明两天缺人的更 ② 待处理报名/未读消息 ③ 今日各池在岗一览。

## 复核修正（用户审阅规格时提出 4 点）
1. 泳池详情卡片报名后的入表路径要理顺。
2. Non-Goals 修改：系统要**生成 WhatsApp 招募文案模板**，主管一键跳转 WhatsApp 转发（先让救生员在 WhatsApp 看到公开信息再点进来）。
3. 点链接后可选**登录或简单注册**。
4. 指出流程分叉混乱（有的主管公开泳池工资、有的不公开）。

**统一为"要约—接受"模型（已确认）**：入表三要素 = 泳池+更次+时薪；**最后一步永远是主管确认**。
- 情形 A（帖内公开）：列表有**直接"报名"按钮**（也可进聊天）→ 主管同意 → 入表（时薪带出公开价可改）。
- 情形 B（保密）：列表**只有"联系以报更"按钮** → 聊天 → 主管发详情卡片 → 救生员接受 → **主管最终确认** → 入表。

**平台修正（已确认）**：先网页全功能上线，**第二期原生 App（iOS+Android，非套壳）**；网页推荐装 App，网站也能完整用。

## R21 通知渠道（含收费调研）
**调研**：WhatsApp Business API 实用类约 HK$0.13–0.2/条（香港 2026-07 起独立计价）；SMS 约 HK$0.5/条（Twilio US$0.068）；Web Push/wa.me 免费。
**关键澄清**：wa.me 跳转按钮（人手按发送）**免费**；收费的是系统自动发（Business API）。
**定案**：第一期全免费组合——站内通知 + Web Push + 关键动作（取消已确认班次等）强制弹 wa.me 跳转预填消息；接受"对方不按发送收不到"的残余风险；不接 API、不发 SMS；第二期 App 原生推送补保证送达。

## R22 账号体系（多轮深挖，最终定稿）
**用户诉求演进**：要保证电话能打通；换号后别人不能仅凭电话登录；SMS 太贵；后改为**用户名永久不变**方案；再加入**平台管理员逐个人工审核**（未认证/已认证）；再要求**忘记密码全自动化**（管理员不想老是亲自帮忙）。

**最终定稿**：
- **简单注册五样**：用户名（永久不改、永不释放复用）、密码、真实姓名、证件照（OCR 姓名比对）、WhatsApp 反向验证（用户从自己 WhatsApp 发验证码给系统号，免费，绑定号码）。注册即建账号【未认证】；**访客态取消**；入表时无需补任何资料。
- **登录**：用户名或手机号（仅找账号）+ 密码；可选 passkey。
- **平台管理员**：独立角色（可多个），人工审核证件 → 已认证/驳回/待复审。未认证不卡业务（可聊天报名入表）但全程高亮；驳回红色警告；主管可查看证件图自行把关（与证书过期同一原则）。
- **忘记密码双闸全自助**：① 绑定号 WhatsApp 发验证码（验证码对+发信号=绑定号）② 重传证件 OCR 比对 → 自动重置。兜底才找管理员。
- **忘记用户名**：脱敏提示。**换号**：登录态改+新号反向验证，号码纯联系字段。
- **18 个边际个案**（号码回收、重复注册、冒用证件、改名、换证、盗号、注销、失联、主管兼任等）逐一验证全部收敛于"密码管进门 / WhatsApp 反向验证管号码 / 证件 OCR+管理员管人 / 保护态冻结自动操作"。
