## 三端页面层级（按页面 ID）

```
主管端 Supervisor（5 分页：总览 / 更表 / 讯息 / 工资 / 我的）
├── S1 首页（总览）
│   ├── 待處理 → 点入 S5「全部待確認報名」聚合列表（所有池所有待确认，非单人）
│   ├── 今日在崗 → 点入 S9「今日各池在岗总览」（一次列全部泳池＋各池全部在岗人，无层级）
│   ├── 招募情报 → §筛选器（工种/地区级联/显示时薪 ＋ 主管专属「只我发布/排除我」）
│   │            展开即筛选，其下用招募卡片（最大字＝地区级联）列出，含自己发布带管理掣
│   └── ＋发布招募（右下角悬浮 FAB → S7）
├── S2 更表（泳池一览）
│   ├── 顶部：今日 / 明日缺人总数两个数字（点数字筛选缺人泳池，可取消）
│   ├── 發布招募 按钮（同首页 → S7）
│   ├── 筛选：地区 + 缺人筛选，展开显示日历（缺人日红底 / 缺人=0 绿底），
│   │        筛选后先显示「这一天缺人总数」；取消筛选恢复（同 .fbar ✕ 取消）
│   └── 海怡半岛 / 黄埔花园 / 嘉湖山庄 → 点海怡 → S3
├── S3 月更表（Excel 式格子系统）
│   ├── 4 位置列（位置 index 1–4）＋ 每人独一色 pill
│   ├── 拖拽交换（HTML5 drag，格子对格子）
│   ├── 一键排更（填缺人格）＋ 一键整理（竖直对齐到各自主列，算法对齐用户示例）
│   ├── 缺人格点击/长按 → 为该格开招募
│   ├── 假期红底只落在「日期 cell + 星期 cell」
│   └── 月份选择行 ◀ 2025年7月 ▶（对齐 SPEC §5/§6 月更表选模板/选月）
├── S5 全部待確認報名（聚合，要约-接受：主管唯一入表触发者）
├── S6 工资
│   ├── 筛选：按月 / 未结 / 已结（级联）
│   ├── 每人工资大卡片（结清也显金额 + 绿字已結 ✓）→ 整卡点进 S6D
│   └── 确认支付掣样式＝「報名」；已删除原「整人一键确认」ghost 掣
├── S6D 工资详情（单日明细 + 单日确认）［新增］
├── S7 发布招募（由 FAB 进入）
├── S8 我的（账号项 + 深色模式开关；已删风格/主题色选择）
└── S9 今日各池在岗总览［新增］

救生员端 Lifeguard（5 分页）
├── L1 注册（改 3 步 + 顶部进度条 + 鼓励文案）
│   ├── 步骤1 基础账号（用户名/密码/电话号码）
│   ├── 步骤2 上传照片 + 真名（【测试壳】任意相过）
│   └── 步骤3 验证码（显示发去边个电话/WhatsApp + 跳转掣；【测试壳】3 秒自动过）
├── L6 登录［新增］（用户名或手机号 + 密码；忘记密码 / 去注册 / passkey 提示）
├── L2 搵工（§筛选器救生员版 + 招募卡片，最大字＝地区，同主管 S1）
├── L3 我的更表（Excel 视觉复用 + 假期只染日期/星期 cell + A−/A＋ 缩放；单人无拖拽；同池同事/主管 WhatsApp 一键跳转）
├── L4 我的工资（每人卡片外层只显主管名 + 全部应付总额 → 点进 L4 详情看单日明细 + 確認已收）
└── L5 讯息（WhatsApp 式会话列表 → 聊天线程）

管理员端 Admin
├── A1 证件审核（通过 / 驳回 → 联动 A2）
└── A2 用户列表
＊仅套用全局 iOS 明暗配色 + 日/夜切换；结构与交互不变。
```
