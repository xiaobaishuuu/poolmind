## 三端页面层级（按页面 ID）

```
主管端 Supervisor（5 分页：总览 / 更表 / 讯息 / 工资 / 我的）
├── S1 首页（总览）
│   ├── 今明缺人总数（今日 / 明日两个数字）── 点数字 → S2 自动筛选缺人泳池
│   ├── 待处理 ── 「最新收到讯息」→ S4 自动筛选最新收到（可取消）
│   ├── 招募情报（L2 卡片组件，置于首页最下面）
│   └── ＋发布招募（右下角悬浮按钮 FAB → S7）
├── S2 更表（泳池一览）
│   ├── 顶部筛选条：只显示缺人泳池（✕ 可取消，显示回全部）
│   └── 海怡半岛 / 黄埔花园 / 嘉湖山庄 ── 点海怡 → S3
├── S3 月更表（Excel 式垂直日历，周六日浅红底）
│   └── 缺人＋ → S5
├── S4 讯息（会话列表层 → 聊天线程层）
│   └── 顶部筛选条：只显示最新收到（✕ 可取消）
├── S5 待处理报名 ── 确认入表（要约-接受）→ 回填 S3 / 更新 S1 今日缺人 / S2 海怡状态
├── S6 工资
├── S7 发布招募（由 S1 悬浮掣进入）
└── S8 我的（界面风格 A/C＋主题色）

救生员端 Lifeguard（5 分页）
├── L1 注册（五样一次过＋两个测试壳）
├── L2 搵工（招募卡片组件；主管首页 S1 沿用此组件）
├── L3 我的更表（Excel 式垂直，周六日浅红底，没上班显示「休息」）
├── L4 我的工资（按主管分组，只见自己时薪）
└── L5 讯息（新增 WhatsApp 式会话列表层 → 点入聊天线程）

管理员端 Admin
├── A1 证件审核（通过 / 驳回 → 联动 A2）
└── A2 用户列表
```
