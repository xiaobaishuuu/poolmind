## 已定案的核心决策（速览）

1. **形态**：响应式网页优先（WhatsApp 链接直接打开），预留日后 App；香港、繁体中文、HKD；先自用、架构预留多租户。
2. **招募报名**：WhatsApp 发链接 → 姓名+救生员证 OCR 姓名比对 → 站内聊天谈薪 → 主管确认时填时薪并强制注册转正；一人多报 + 主管抢人 + 冲突隐藏/恢复。
3. **排更**：泳池模板定义更次（时段/人数/默认价/冬夏规格一键切换）；报名勾到更次级别；拖拽只能放进报过的可用更次；一键排班：偏好名单（含最少人数 N）→ 连续性 → 尽力而为并展示方案。
4. **工资**：更表即考勤（无打卡）；时薪三层覆盖：单日改价 > 人×池绑定价 > 泳池默认价；价格对救生员不可见（只在自己工资单看到自己的价）；每晚 00:00 汇总；过去日期锁死、只允许加钱/扣钱调整项（附原因）；7 状态支付确认状态机（7 天自动确认、撤回规则、主管兼救生员自付直达双向确认）。
5. **权限**：主管垂直层级（权限 = 自己泳池 + 下级全链）；主管可上传资历兼任救生员；救生员端有自己的更表 + 按主管分组的工资单。
6. **变动**：取消已确认班次需二次确认框 + 立即通知管辖主管；短更取消班次重开并恢复被隐藏报名者；长更取消留空由排班工具箱处理；未确认报名可静默撤回。
