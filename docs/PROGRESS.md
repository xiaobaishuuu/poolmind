## 全部已定案的核心决策（速览）

1. **形态**：第一期响应式网页全功能；第二期原生 App（iOS+Android 非套壳）；香港/繁中/HKD；先自用、预留多租户。
2. **招募**：长期通用链接 + **分层披露**（主管自选公开字段；聊天内发泳池详情卡片才露屋苑）；系统生成 WhatsApp 文案一键转发。
3. **报名（要约—接受统一模型）**：情形 A（公开）直接报名按钮→主管同意入表；情形 B（保密）"联系以报更"→聊天→详情卡片→接受→**主管最终确认**入表；主管是唯一入表触发者；一人多报+抢人+冲突隐藏/恢复。
4. **聊天**：主管×救生员人对人永久会话。
5. **排更**：泳池任意多个自由命名模板（按星期几定义更次、人数、默认价、备注）；月更表创建时选模板，改模板可选生效范围并列冲突；拖拽仅限已报可用更次；一键排班：偏好名单（最少 N 人）→连续性→尽力而为。
6. **工资**：更表即考勤；时薪三层覆盖（单日>人×池绑定>默认）；救生员看不到任何价格（自己的价只在工资单）；每晚 00:00 汇总；过去锁死+加/扣调整项（附原因）；7 状态支付确认状态机（7 天自动确认、撤回规则、自付直达双向确认）；**Excel 导出**（按月/泳池/人）。
7. **账号（R22 定稿）**：简单注册五样（**用户名永久不改**、密码、姓名、证件 OCR、WhatsApp 反向验证）；访客态取消；登录=用户名或手机号+密码；**平台管理员独立角色**人工审核（未认证/已认证/驳回/待复审，未认证可入表但高亮）；**忘记密码双闸全自助**（绑定号 WhatsApp 验证码 + 证件 OCR）零 SMS 零人工；手机号纯联系字段；保护态冻结自动操作；18 个边际个案全部收敛。
